## Скачать

Готовые файлы — в разделе **Releases**:

| Файл | Что это |
|---|---|
| `AnixDesktop-Setup-1.3.0.exe` | установщик: ярлыки на рабочем столе и в «Пуске», можно выбрать папку; права администратора не нужны |

Установщик не подписан — Windows SmartScreen может предупредить: «Подробнее» → «Выполнить в любом случае».

**Обновления — из самого приложения** (в версиях новее 1.5.0): при запуске оно проверяет, вышла ли новая версия, и показывает,
что в ней нового. «Обновить» скачивает её с прогрессом, ставит поверх и перезапускает приложение — вход и настройки
сохраняются. Без согласия ничего не скачивается; «Пропустить эту версию» — больше о ней не напоминать.

**Для AI-помощника нужен аккаунт Claude** — подписка Pro/Max или Anthropic Console (оплата по API).
Claude Code отдельно ставить не нужно: он уже встроен в сборку, поэтому установщик и весит ~210 МБ.
Всё остальное приложение работает и без Claude.

**Версия для браузера** — архив «Source code» того же релиза: нужен Node.js 18+, распакуйте и запустите
`start-browser.bat` → http://127.0.0.1:8371/. Источники VK Видео и StudioMir в ней работают только
с ключами (см. «Ключи сторонних сервисов»); из соцсетей доступен только Google, AI-помощник — после `npm install`.

## Запуск из исходников

```
npm install
npm run app        Windows-приложение (Electron)
npm start          версия для браузера (http://127.0.0.1:8371/)
```

Новые версии npm не запускают install-скрипты без разрешения. Если после `npm install` нет
`node_modules/electron/dist/electron.exe`, выполните `npm install-scripts approve electron` и повторите `npm install`
(или `node node_modules/electron/install.js`).

### Ключи сторонних сервисов

Ключи источников видео и входа через соцсети в репозитории не хранятся. Без них приложение работает,
но недоступны:

| Ключ (`config.example.json`) | Без него |
|---|---|
| `kodik.token` | ничего: Kodik работает без ключа (через kodikplayer.com/ftor), токен — запасной путь |
| `studiomir.apiKey` | источник StudioMir |
| `vkVideo.clientId`, `vkVideo.clientSecret` | источник VK Видео |
| `discord.clientId` | статус «Смотрит …» в Discord (Application ID приложения с [discord.com/developers](https://discord.com/developers/applications); его название видно в статусе) |
| `social.*` | вход через Google, Telegram, VK, Яндекс (кнопки скрываются) |

Скопируйте `config.example.json` в `config.local.json` (он в `.gitignore`) и заполните нужные поля.
Сервер ищет конфиг по порядку: путь из `ANIX_CONFIG` → `config.local.json` в корне → `~/.anixart-desktop/config.json`.
Готовые сборки из Releases уже содержат конфиг — там всё работает сразу.

## Возможности

Все основные разделы: Главная (вкладки и «Моя вкладка» с фильтром), Обзор, Закладки, Лента и каналы, Профиль, релиз,
озвучки и серии, поиск, фильтр, коллекции, комментарии и ответы, уведомления, вход/регистрация/восстановление, настройки.

- **Плеер**: встроенный (HLS), веб-плеер и сторонний (mpv/VLC); двойной клик по краю ±10 с с накоплением,
  удержание — скорость ×2 от текущей (1.25 → 2.5x), пропуск опенинга и эндинга по меткам источника
  (Kodik, AniLibria) с их секциями на таймлайне, меню-шестерёнка (качество, скорость, автопропуск),
  автовоспроизведение, диалог
  «Начать сначала / Продолжить»; Kodik — сразу в 720p, без рекламы.
- **Улучшение картинки** нейросетью во встроенном плеере, с ускорением на NVIDIA RTX — см. ниже.
- **Улучшение звука** во встроенном плеере — три переключателя, см. ниже.
- **Совместный просмотр** — комната по коду или ссылке: пауза, перемотка, серия и скорость у всех одновременно,
  очередь «Дальше», чат; без своего сервера — см. ниже.
- **Путь до серии в один клик**: на странице аниме «Продолжить · 5 серия» сразу запускает плеер с того же места
  (просмотренная часть кнопки залита, справа «ещё 12 мин»), рядом «⏭ 6 серия»; досмотрели до эндинга — «Смотреть
  6 серию». Учитывается и последняя серия с других устройств (Anixart на телефоне). Серии — один экран: над списком
  чипы озвучки (с логотипом и поиском), источника (с качеством: Kodik — до 720p, AniLiberty / AniLibria — до 1080p) и плеера,
  смена на месте; в первый раз озвучка выбирается прямо там и запоминается. Отметки просмотра общие для аниме — в
  любой озвучке. В самом плеере сверху те же переключатели: озвучка (продолжает с того же места), серия, плеер.
- **Качество в веб-плеере** (Windows-приложение): плеер AniLibria сам ставит 720p — приложение переключает его
  по настройке «Приоритет качества» (по умолчанию — максимальное, 1080p).
- **Пропуск филлеров**: переключатель в настройках и в плеере — «следующая серия» (кнопка, N, после эндинга,
  автозапуск), «Смотреть N серию» и «⏭» перескакивают филлеры, в плеере — «Пропущено 3 филлера — сейчас 139 серия».
  В совместном просмотре это настройка комнаты (меняет хост), остальным приходит уведомление.
- **Мини-плеер**: плеер сворачивается в угол — серия идёт, а каталог можно листать.
- **Статус в Discord**: «Смотрит <тайтл>» — серия, озвучка, постер, полоса времени серии (с учётом паузы и скорости)
  и кнопка «Открыть в Anixart». По умолчанию выключен — включается переключателем «Статус в Discord» в настройках
  (там же состояние: «Discord подключён / не запущен»). Привязывать ничего не нужно: статус уходит в Discord,
  запущенный на этом же компьютере, — и из приложения, и из браузерного режима. Свой клиент локального протокола Discord в локальном сервере (`server/discord.js`), без библиотек;
  частые события плеера склеиваются под лимит Discord (5 обновлений за 20 с), Discord, запущенный позже, подхватывается;
  статус меняет только само приложение — запросы с чужих сайтов к локальному серверу отклоняются.
- **Настройки по разделам** (меню слева, в узком окне — полосой сверху): внешний вид, воспроизведение, картинка
  и звук, Discord, AI-помощник, дополнительно, аккаунт, о приложении. Как в мобильном приложении: «Запоминать вариант
  и источник»; «Альтернативное соединение» (зеркала статики, API и плеера — `mirror-s.anixmirai.com` и т. п.); «Режим
  экономии ресурсов» (без анимаций); «Очистить веб-кэш»; тема, вид списков, качество, плееры. И то, что раньше было
  только в плеере или на Главной: скорость, пропуск опенинга и эндинга, вкладка Главной по умолчанию, уведомления.
- **Скорость интерфейса**: скелетоны вместо спиннеров на всех экранах (у каждого экрана свой — в той же
  раскладке, что и контент); релиз, канал, запись и коллекция открываются мгновенно с данными карточки
  (`preload`), остальное догружается; предзагрузка релиза, когда курсор остановился на карточке.
- **Как в мобильном приложении**: ЛКМ + движение прокручивает списки (а не выделяет текст), плавные переходы
  между экранами, у каждой вкладки свой стек экранов с сохранением прокрутки.
- **Автообновление** (Windows-приложение): при запуске — окно «Вышла новая версия» с «Что нового» из текста релиза,
  «Обновить» — скачивание с прогрессом (по `.blockmap` докачиваются только изменившиеся части), тихая установка поверх
  и перезапуск; «Пропустить эту версию». Окно не открывается поверх плеера — ждёт, пока его закроют. В «Настройки →
  О приложении» — «Проверить обновления» и «Что нового».
- **Вход через соцсети**: Яндекс, ВКонтакте, Telegram, Google — см. ниже.
- **AI-помощник** — отдельная вкладка, нужен аккаунт Claude, см. ниже.

## Улучшение картинки

<img src="docs/screenshots/upscale.jpg" alt="Шторка «Оригинал / Улучшено» в плеере: слева исходный кадр, справа улучшенный">

<img src="docs/screenshots/upscale-zoom.jpg" alt="Фрагмент кадра крупно: оригинал размыт, после улучшения — чёткие линии">

Нейросеть в реальном времени увеличивает серию до размера экрана (WebGPU, любая видеокарта с его поддержкой).
На снимках — «Торадора!» из Kodik: подписано «720p», а внутри растянутый DVD; плеер сам это определил и включил
модель для SD (AnimeJaNai SD Compact).

- **Режимы** в шестерёнке плеера: «Выкл / Авто / Лёгкое / Сильное / Максимальное» и разрешение (под окно,
  1080p, 1440p, 4K). Шторка «Оригинал / Улучшено», удержание C — оригинал, U — вкл/выкл.
- **Качество серии — по самим кадрам**, а не по подписи «720p»: плеер меряет, насколько картинка мягче своего
  размера (чёткий исходник / мягкий HD / растянутый SD), и запоминает это для тайтла и озвучки — со следующей
  серии всё включается сразу.
- **«Авто»** подбирает модель под исходник и скорость видеокарты (замеряется на реальных кадрах): при нехватке
  скорости молча берёт модель полегче, а когда видеокарта освободится — возвращается. Бенчмарк (при первом
  включении, несколько секунд) меряет каждую сеть на WebGPU и TensorRT.
- **Ручной уровень** не меняется сам — если видеокарта не успевает, плеер один раз об этом скажет. Пресеты:
  ArtCNN C4F16/C4F32, AnimeJaNai V3.1 Performance/Balanced, V3 SuperUltraCompact, AnimeJaNai SD, AniSD AC — с
  временем на кадр; «Резкость»: Мягче — ближе к исходнику и без мерцания, Обычно — лучшее для этой серии,
  Резче — чётче линии.
- **Ускорение NVIDIA**: на GeForce RTX (20-я серия и новее) тяжёлые модели считает TensorRT на тензорных ядрах —
  в 2–4 раза быстрее (V3.1 Balanced на 720p: 17 мс на кадр против 30). Библиотеки NVIDIA (93 МБ) в установщик
  не входят — скачиваются по кнопке «Установить» в меню улучшения или в настройках. CUDA ставить не нужно — она
  внутри; нужен драйвер NVIDIA версии 580 или новее (со старым приложение подскажет обновить).
- **GTX, AMD, Intel**: улучшение работает на WebGPU, без ускорения.

Модели выбраны по замерам на 650 кадрах и видеоотрывках (резкость, артефакты, мерцание); их лицензии — в
[NOTICE.md](NOTICE.md).

## Улучшение звука

Шестерёнка плеера → «Звук» (или настройки → «Картинка и звук»), три переключателя в любом сочетании:

- **Выравнивать громкость** — тихие реплики громче (шёпот — примерно на 10 дБ), взрывы и крики тише: удобно ночью
  и когда озвучки записаны с разной громкостью.
- **Чёткий голос** — озвучка почти всегда стоит по центру стерео: плеер поднимает центр и диапазон разборчивости
  речи над музыкой и эффектами (≈ +3 дБ голоса над фоном), общая громкость не меняется.
- **Объёмный звук** — для наушников: виртуальные колонки спереди (±30°) и сзади (±110°) с короткой «комнатой»,
  звук слышится вокруг, а не внутри головы. Работает на встроенном в Chromium HRTF (усреднённые замеры IRCAM).

Всё на Web Audio, без скачиваний и без видеокарты. Обработка не добавляет задержки: компрессор Chromium и HRTF в
PannerNode задерживают звук на 6 мс каждый, поэтому выравнивание сделано своим AudioWorklet без заглядывания вперёд
(`audio-leveler.js`), а отклик HRTF один раз снимается офлайн и подаётся в свёртку (у ConvolverNode задержки нет).
Перегрузку срезает мягкое ограничение (WaveShaper), тоже без задержки.

**Синхронизация с картинкой.** Звук берётся через `video.captureStream()`, а не `createMediaElementSource`: тот
забирает звук у `<video>` навсегда, и браузер перестаёт подгонять его под картинку — звук отставал на 35–38 мс, и
выключение переключателей это не убирало. Захват идёт и при заглушённом элементе: пока улучшение включено, `<video>`
молчит, а громкость и mute плеера задаёт Web Audio; выключили — элемент снова звучит сам, с родной синхронизацией,
захват останавливается, AudioContext засыпает. Захваченный звук приходит чуть раньше картинки, задержка в 10 мс ставит
его вровень: по замерам расхождение от −8 до +10 мс.

## Совместный просмотр

Кнопка «Смотреть вместе» — на странице аниме рядом с «Смотреть» / «Продолжить», в плеере и в верхней панели (👥 с числом
участников). Друзья входят по коду `XXXX-XXXX-XXXX` или по ссылке-приглашению `anixdesktop://watch/<код>` —
серия комнаты открывается сама.

- **Синхронно**: пауза, перемотка, следующая/предыдущая серия и скорость — у всех. Смена серии ждёт, пока она
  загрузится у каждого (не дольше 10 с), и запускает всех разом. Рассинхрон до 2,5 с выравнивается плавно
  скоростью (±10 %), больше — перемоткой с упреждением на время догрузки. По замерам — расхождение 0,0–0,2 с.
- **Очередь «Дальше»**: другое аниме не обрывает серию — выбранное встаёт в очередь («Аня предлагает…»), включить
  может любой, кому разрешено управлять; кончились серии — включается первое из очереди. Хост перетаскивает и
  удаляет, своё предложение может убрать автор. На странице аниме в комнате — «Предложить комнате».
- **Хост** может оставить управление только себе. Ушёл — хостом становится самый давний участник.
- **Мини-плеер**: свернуть плеер в угол и выбирать дальше в каталоге, не прерывая просмотра.
- Видео каждый берёт сам, со своими настройками картинки, звука и качества. Встроенный плеер обязателен: веб-плеер
  синхронизировать нельзя.

**Как устроено, без своего сервера.** Команды идут через три публичных MQTT-брокера сразу (HiveMQ,
test.mosquitto.org, EMQX): сообщение уходит во все, повторы отбрасываются, так что сбой одного не мешает. Брокеры
видят только тему-хеш и шифротекст — ключ AES-GCM и тема выводятся из кода комнаты (PBKDF2, 150 тыс. итераций).
Состояние комнаты и присутствие хранятся у брокеров (retain): вошедший сразу получает их; «последняя воля» брокера
сообщает, что участник пропал без выхода. Часы участников сравниваются пингами, как NTP (могут врать хоть на
минуты), опорную точку раз в 5 с переопубликует самый давний участник. Сторож переподключает брокер, от которого
25 с ничего не приходило: так переживаются обрывы и провайдеры, «замораживающие» долгие соединения с зарубежными
хостингами. Из России (узлы check-host в Москве и Петербурге) все три брокера доступны; на домашнем интернете с
ограничениями, по-хорошему, стоит проверить. Схема синхронизации — по Syncplay и Jellyfin SyncPlay.

## AI-помощник

<img src="docs/screenshots/ai.jpg" alt="AI-помощник подбирает аниме по истории просмотров">

Вкладка **AI** (шестая в меню) — чат с Claude, который видит аккаунт Anixart и помогает выбрать, что посмотреть,
а по просьбе сам меняет закладки, оценки и коллекции.

**Вход.** По порядку: аккаунт Anixart → аккаунт Claude (подписка Pro/Max или Anthropic Console — откроется окно
входа) → чат. Вход в Claude общий с Claude Code (`~/.claude`): если вы уже вошли там, повторять не нужно.
Запросы расходуют лимиты вашей подписки Claude.

**Что умеет** (`public/js/ai-tools.js`):

| Группа | Инструменты |
|---|---|

Изменения помощник делает сразу, когда пользователь просит, без подтверждений; без просьбы ничего не меняет
(так задано в системном промпте). Упомянутые релизы показываются в чате карточками с постерами.

**Память** — `~/.anixart-desktop/ai/memories/<id аккаунта>.md`, обычный Markdown (можно править руками).
Помощник сам записывает устойчивые предпочтения (жанры, формат просмотра, явные «запомни»); в начале каждой
беседы файл целиком попадает в системный промпт. Чтобы память не съедала контекст, она жёстко ограничена:
40 записей по 200 символов, не больше 4000 символов (≈1–1,5 тыс. токенов). При переполнении `remember`
отказывает и просит сначала объединить или удалить записи — память сжимает сам помощник.
Посмотреть, удалить запись или очистить всё — кнопка «Память» в шапке чата.

**История бесед** — кнопка «История»: до 30 бесед на аккаунт, возврат к беседе восстанавливает и контекст
агента (`session/load`). **«+»** — новая беседа, **«Стоп»** — прервать ответ.

**Модель и глубина рассуждений** — «Настройки → AI-помощник»: по умолчанию **Sonnet 5.5** и effort **medium**;
можно выбрать Opus 5.5, Haiku 5.5, Fable 5.1 и effort от low до max. Смена применяется и к текущей беседе.

**Как устроено**:

```
фронтенд ──POST /ai/*, SSE /ai/events──► server/ai.js ──ACP (stdio)──► claude-agent-acp ──► claude.exe
claude.exe ──MCP (HTTP) /mcp/<ключ>──► server/ai.js ──SSE──► фронтенд выполняет инструмент ──POST /ai/tool-result
```

- Агент — [`@agentclientprotocol/claude-agent-acp`](https://github.com/agentclientprotocol/claude-agent-acp)
  (Agent Client Protocol) со встроенным `claude.exe` из `@anthropic-ai/claude-agent-sdk-win32-x64`.
  Запускается через Electron как Node (`ELECTRON_RUN_AS_NODE`), отдельный Node.js не нужен.
- Инструменты Anixart выполняются во фронтенде (там токен, готовые вызовы API, локальная история, навигация);
  сервер только ретранслирует вызовы. Память обрабатывается на сервере (`server/ai-memory.js`).
- Ограничения агента: из встроенных инструментов Claude Code — только поиск в интернете; рабочая папка —
  пустая `~/.anixart-desktop/ai`; ваши настройки, `CLAUDE.md`, хуки и MCP из `~/.claude` не подключаются
  (`settingSources: []`, `strictMcpConfig`); режим разрешений ручной, инструменты приложения разрешены списком.
- Работает в Windows-приложении и при запуске из исходников после `npm install` (в т. ч. в браузере). Без
  установленных зависимостей (архив «Source code» как есть) вкладка сообщит, что помощник недоступен.

## Вход через соцсети

- **Яндекс, ВКонтакте, Telegram** (только Windows-приложение): официальная страница провайдера открывается
  в окне приложения, оно перехватывает `redirect_uri`, и токен отправляется на бекенд Anixart (`auth/<провайдер>`).
- **Google** (Windows-приложение и браузерная версия): во встроенных окнах Google вход запрещает, поэтому
  открывается обычный браузер со страницей `http://localhost:<порт>/google-auth.html`. Она входит через
  Firebase и возвращает токен в приложение.

Нужны ключи `social.*` в конфиге (см. «Ключи сторонних сервисов»). Вход по логину и паролю работает везде.

## Где хранятся данные

- **localStorage окна приложения** (`%APPDATA%\Anix Desktop`): вход в Anixart, настройки, локальные отметки серий
  и позиции, история поиска, беседы AI (`anixart.ai.chats.<id>`); для улучшения картинки — замеры видеокарты
  (`UPSCALE_BENCH`) и оценки «настоящего» разрешения по источникам (`UPSCALE_NATIVE`, последние 300).
- **`%APPDATA%\Anix Desktop\trt-rtx`** и **`trt-cache`**: библиотеки TensorRT (после «Установить») и собранные под
  видеокарту движки моделей — удалить папки, чтобы убрать ускорение NVIDIA.
- **`~/.anixart-desktop/ai/`**: рабочая папка AI-агента и `memories/<id>.md` — память помощника.
- **`~/.claude/`**: вход в Claude (общий с Claude Code) и сессии агента — по ним восстанавливаются беседы.
- **`%LOCALAPPDATA%nix-desktop-updater`**: скачанный установщик обновления (и копия для докачки следующего).

## Проверка

Тесты запускаются в скрытом окне Electron против живого бекенда Anixart (`npx electron test/<файл>.js`).
Экран считается загруженным, когда закончились запросы, скелетоны и проявление картинок (`test/_settle.js`), —
фиксированных пауз почти нет.
Тесты `ai-*` требуют входа в Claude на машине и расходуют немного лимитов; вход в Anixart в них фиктивный,
а изменяющие запросы к бекенду в `ai-actions` подменены — реальный аккаунт не затрагивается.


## Анимации (Lottie)

Анимации интерфейса (сердце «в избранное», колокольчик, звёзды оценки, галочка в тостах, пустые экраны) —
Lottie, в приложении их проигрывает lottie-web (`public/js/lottie.js`). Источник — сцены плеера скилла
[text-to-lottie](https://github.com/diffusionstudio/lottie) в `tools/lottie-studio/public/projects/anix-ui/`:

```
cd tools/lottie-studio && npm install && npm run dev   плеер (Skia Skottie): кадры, слоты цвета
node tools/lottie-studio/sync.mjs                      сцены → public/lottie/*.json для приложения
```

Цвет в приложении задаёт тема (классы слоёв `cl` и CSS), в плеере — слоты. Отрезки для проигрывания — маркеры сцены.

## Сборка и релиз

```
npm run build:win        портативная папка release\win-unpacked
npm run build:installer  установщик в release\
npm run build:release    файлы релиза в release\: установщик, его .blockmap и latest.yml (для автообновления)
```

**Релизы собирает GitHub Actions** по тегу `vX.Y.Z` — шаги в [docs/RELEASE.md](docs/RELEASE.md). Команды выше —
для локальной сборки.

`config.local.json`, если он есть, попадает в сборку; `node build/release.js --no-keys` — собрать без него.
Иконка: `build/icon.svg` → `npx electron build/make-icons.js` (icon.png, icon.ico, public/icon.png).

`node_modules` распаковываются из asar (`asarUnpack`): адаптер и `claude.exe` запускаются отдельным процессом
и не могут работать из архива.

**Ускорение NVIDIA** (`trt/bin/anix-trt.exe`, кладётся в ресурсы сборки) собирается отдельно, один раз:
`node trt/build.js`. Нужны Visual Studio Build Tools (C++) и CUDA Toolkit 13.x; SDK TensorRT for RTX (заголовки
и import-библиотеки) скрипт скачает в `trt/sdk` сам. Exe не зависит от DLL CUDA и рантайма MSVC; библиотеки
TensorRT подгружает из папки, которую ему передаёт приложение (`%APPDATA%\Anix Desktop\trt-rtx`).
Для тестов без установки библиотек в профиль: `ANIX_TRT_DLLS=trt/sdk/TensorRT-RTX-1.7.1.116/bin`.
