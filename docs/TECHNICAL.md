## Сборки

Готовые файлы — в разделе [Releases](https://github.com/arigandores/anix/releases/latest):

| Файл | Что это |
|---|---|
| `Anix-Setup-<версия>.exe` | установщик: ярлыки на рабочем столе и в «Пуске», можно выбрать папку; права администратора не нужны |
| `Anix-Setup-<версия>.exe.blockmap`, `latest.yml` | для автообновления (докачка изменившихся частей) |

Установщик не подписан — Windows SmartScreen может предупредить: «Подробнее» → «Выполнить в любом случае».

**Обновления — из самого приложения** (в версиях новее 1.5.0): при запуске оно проверяет, вышла ли новая версия, и показывает,
что в ней нового. «Обновить» скачивает её с прогрессом, ставит поверх и перезапускает приложение — вход и настройки
сохраняются. Без согласия ничего не скачивается; «Пропустить эту версию» — больше о ней не напоминать.

**Для AI-помощника нужен аккаунт Claude** — подписка Pro/Max или Anthropic Console (оплата по API).
Claude Code отдельно ставить не нужно: он уже встроен в сборку, поэтому установщик и весит ~210 МБ.
Всё остальное приложение работает и без Claude.

**Версия для браузера** — архив «Source code» того же релиза: нужен Node.js 18+, распакуйте и запустите
`start-browser.bat` → http://127.0.0.1:8371/. Источники VK Видео и StudioMir в ней работают только
с ключами (см. «Ключи сторонних сервисов»); из соцсетей доступен только Google, AI-помощник — после `npm install`.

## Запуск из исходников

```
npm install
npm run app        Windows-приложение (Electron)
npm start          версия для браузера (http://127.0.0.1:8371/)
```

Новые версии npm не запускают install-скрипты без разрешения. Если после `npm install` нет
`node_modules/electron/dist/electron.exe`, выполните `npm install-scripts approve electron` и повторите `npm install`
(или `node node_modules/electron/install.js`).

### Ключи сторонних сервисов

Ключи источников видео и входа через соцсети в репозитории не хранятся. Без них приложение работает,
но недоступны:

| Ключ (`config.example.json`) | Без него |
|---|---|
| `kodik.token` | ничего: Kodik работает без ключа (через kodikplayer.com/ftor), токен — запасной путь |
| `studiomir.apiKey` | источник StudioMir |
| `vkVideo.clientId`, `vkVideo.clientSecret` | источник VK Видео |
| `discord.clientId` | статус «Смотрит …» в Discord (Application ID приложения с [discord.com/developers](https://discord.com/developers/applications); его название видно в статусе) |
| `social.*` | вход через Google, Telegram, VK, Яндекс (кнопки скрываются) |

Скопируйте `config.example.json` в `config.local.json` (он в `.gitignore`) и заполните нужные поля.
Сервер ищет конфиг по порядку: путь из `ANIX_CONFIG` → `config.local.json` в корне → `~/.anixart-desktop/config.json`.
Готовые сборки из Releases уже содержат конфиг — там всё работает сразу.

## Возможности — подробно

Все основные разделы: Главная (вкладки и «Моя вкладка» с фильтром), Обзор, Закладки, Лента и каналы, Профиль, релиз,
озвучки и серии, поиск, фильтр, коллекции, комментарии и ответы, уведомления, вход/регистрация/восстановление, настройки.

- **Плеер**: встроенный (HLS), веб-плеер и сторонний (mpv/VLC); двойной клик по краю ±10 с с накоплением,
  удержание — скорость ×2 от текущей (1.25 → 2.5x), пропуск опенинга и эндинга по меткам источника
  (Kodik, AniLibria) с их секциями на таймлайне, меню-шестерёнка (качество, скорость, автопропуск),
  автовоспроизведение, диалог
  «Начать сначала / Продолжить»; Kodik — сразу в 720p, без рекламы.
- **Улучшение картинки** нейросетью во встроенном плеере, с ускорением на NVIDIA RTX — см. ниже.
- **Улучшение звука** во встроенном плеере — три переключателя, см. ниже.
- **Совместный просмотр** — комната по коду или ссылке: пауза, перемотка, серия и скорость у всех одновременно,
  очередь «Дальше», чат; без своего сервера — см. ниже.
- **Путь до серии в один клик**: на странице аниме «Продолжить · 5 серия» сразу запускает плеер с того же места
  (просмотренная часть кнопки залита, справа «ещё 12 мин»), рядом «⏭ 6 серия»; досмотрели до эндинга — «Смотреть
  6 серию». Учитывается и последняя серия с других устройств (Anixart на телефоне). Серии — один экран: над списком
  чипы озвучки (с логотипом и поиском), источника (с качеством: Kodik — до 720p, AniLiberty / AniLibria — до 1080p) и плеера,
  смена на месте; в первый раз озвучка выбирается прямо там и запоминается. Отметки просмотра общие для аниме — в
  любой озвучке. В самом плеере сверху те же переключатели: озвучка (продолжает с того же места), серия, плеер.
- **Качество в веб-плеере** (Windows-приложение): плеер AniLibria сам ставит 720p — приложение переключает его
  по настройке «Приоритет качества» (по умолчанию — максимальное, 1080p).
- **Пропуск филлеров**: переключатель в настройках и в плеере — «следующая серия» (кнопка, N, после эндинга,
  автозапуск), «Смотреть N серию» и «⏭» перескакивают филлеры, в плеере — «Пропущено 3 филлера — сейчас 139 серия».
  В совместном просмотре это настройка комнаты (меняет хост), остальным приходит уведомление.
- **Мини-плеер**: плеер сворачивается в угол — серия идёт, а каталог можно листать.
- **Картинка в картинке** (кнопка в плеере или I): серия в маленьком окне поверх всех окон, плеер из приложения
  уходит целиком. В окне — следующая/предыдущая серия и ±10 с (и клавиши мультимедиа), следующая серия
  продолжается с места без вопроса. «Назад во вкладку» и ✕ — плеер во весь размер, серия идёт дальше;
  закрыли плеер — окно закрывается вместе с ним.
- **Статус в Discord**: «Смотрит <тайтл>» — серия, озвучка, постер, полоса времени серии (с учётом паузы и скорости)
  и кнопка «Открыть в Anixart». По умолчанию выключен — включается переключателем «Статус в Discord» в настройках
  (там же состояние: «Discord подключён / не запущен»). Привязывать ничего не нужно: статус уходит в Discord,
  запущенный на этом же компьютере, — и из приложения, и из браузерного режима. Свой клиент локального протокола Discord в локальном сервере (`server/discord.js`), без библиотек;
  частые события плеера склеиваются под лимит Discord (5 обновлений за 20 с), Discord, запущенный позже, подхватывается;
  статус меняет только само приложение — запросы с чужих сайтов к локальному серверу отклоняются.
- **Настройки по разделам** (меню слева, в узком окне — полосой сверху): внешний вид, воспроизведение, картинка
  и звук, Discord, AI-помощник, дополнительно, аккаунт, о приложении. Как в мобильном приложении: «Запоминать вариант
  и источник»; «Альтернативное соединение» (зеркала статики, API и плеера — `mirror-s.anixmirai.com` и т. п.); «Режим
  экономии ресурсов» (без анимаций); «Очистить веб-кэш»; тема, вид списков, качество, плееры. И то, что раньше было
  только в плеере или на Главной: скорость, пропуск опенинга и эндинга, вкладка Главной по умолчанию, уведомления.
- **Скорость интерфейса**: скелетоны вместо спиннеров на всех экранах (у каждого экрана свой — в той же
  раскладке, что и контент); релиз, канал, запись и коллекция открываются мгновенно с данными карточки
  (`preload`), остальное догружается; предзагрузка релиза, когда курсор остановился на карточке.
- **Как в мобильном приложении**: ЛКМ + движение прокручивает списки (а не выделяет текст), плавные переходы
  между экранами, у каждой вкладки свой стек экранов с сохранением прокрутки.
- **Автообновление** (Windows-приложение): при запуске — окно «Вышла новая версия» с «Что нового» из текста релиза,
  «Обновить» — скачивание с прогрессом (по `.blockmap` докачиваются только изменившиеся части), тихая установка поверх
  и перезапуск; «Пропустить эту версию». Окно не открывается поверх плеера — ждёт, пока его закроют. В «Настройки →
  О приложении» — «Проверить обновления» и «Что нового».
- **Вход через соцсети**: Яндекс, ВКонтакте, Telegram, Google — см. ниже.
- **AI-помощник** — отдельная вкладка, нужен аккаунт Claude, см. ниже.

## Улучшение картинки

Нейросеть в реальном времени увеличивает серию до размера экрана (WebGPU, любая видеокарта с его поддержкой).
На снимках в README — «Торадора!» из Kodik: подписано «720p», а внутри растянутый DVD; плеер сам это определил и включил
модель для SD (AnimeJaNai SD Compact).

- **Режимы** в шестерёнке плеера: «Выкл / Авто / Лёгкое / Сильное / Максимальное» и разрешение (под окно,
  1080p, 1440p, 4K). Шторка «Оригинал / Улучшено», удержание C — оригинал, U — вкл/выкл.
- **Качество серии — по самим кадрам**, а не по подписи «720p»: плеер меряет, насколько картинка мягче своего
  размера (чёткий исходник / мягкий HD / растянутый SD), и запоминает это для тайтла и озвучки — со следующей
  серии всё включается сразу.
- **«Авто»** подбирает модель под исходник и скорость видеокарты (замеряется на реальных кадрах): при нехватке
  скорости молча берёт модель полегче, а когда видеокарта освободится — возвращается. Бенчмарк (при первом
  включении, несколько секунд) меряет каждую сеть на WebGPU и TensorRT.
- **Ручной уровень** не меняется сам — если видеокарта не успевает, плеер один раз об этом скажет. Пресеты:
  ArtCNN C4F16/C4F32, AnimeJaNai V3.1 Performance/Balanced, V3 SuperUltraCompact, AnimeJaNai SD, AniSD AC — с
  временем на кадр; «Резкость»: Мягче — ближе к исходнику и без мерцания, Обычно — лучшее для этой серии,
  Резче — чётче линии.
- **Ускорение NVIDIA**: на GeForce RTX (20-я серия и новее) тяжёлые модели считает TensorRT на тензорных ядрах —
  в 2–4 раза быстрее (V3.1 Balanced на 720p: 17 мс на кадр против 30). Библиотеки NVIDIA (93 МБ) в установщик
  не входят — скачиваются по кнопке «Установить» в меню улучшения или в настройках. CUDA ставить не нужно — она
  внутри; нужен драйвер NVIDIA версии 580 или новее (со старым приложение подскажет обновить).
- **GTX, AMD, Intel**: улучшение работает на WebGPU, без ускорения.

Модели выбраны по замерам на 650 кадрах и видеоотрывках (резкость, артефакты, мерцание); их лицензии — в
[NOTICE.md](../NOTICE.md).

## Улучшение звука

Шестерёнка плеера → «Звук» (или настройки → «Картинка и звук»), три переключателя в любом сочетании:

- **Выравнивать громкость** — тихие реплики громче (шёпот — примерно на 10 дБ), взрывы и крики тише: удобно ночью
  и когда озвучки записаны с разной громкостью.
- **Чёткий голос** — озвучка почти всегда стоит по центру стерео: плеер поднимает центр и диапазон разборчивости
  речи над музыкой и эффектами (≈ +3 дБ голоса над фоном), общая громкость не меняется.
- **Объёмный звук** — для наушников: виртуальные колонки спереди (±30°) и сзади (±110°) с короткой «комнатой»,
  звук слышится вокруг, а не внутри головы. Работает на встроенном в Chromium HRTF (усреднённые замеры IRCAM).

Всё на Web Audio, без скачиваний и без видеокарты. Обработка не добавляет задержки: компрессор Chromium и HRTF в
PannerNode задерживают звук на 6 мс каждый, поэтому выравнивание сделано своим AudioWorklet без заглядывания вперёд
(`audio-leveler.js`), а отклик HRTF один раз снимается офлайн и подаётся в свёртку (у ConvolverNode задержки нет).
Перегрузку срезает мягкое ограничение (WaveShaper), тоже без задержки.

**Синхронизация с картинкой.** Звук берётся через `video.captureStream()`, а не `createMediaElementSource`: тот
забирает звук у `<video>` навсегда, и браузер перестаёт подгонять его под картинку — звук отставал на 35–38 мс, и
выключение переключателей это не убирало. Захват идёт и при заглушённом элементе: пока улучшение включено, `<video>`
молчит, а громкость и mute плеера задаёт Web Audio; выключили — элемент снова звучит сам, с родной синхронизацией,
захват останавливается, AudioContext засыпает. Захваченный звук приходит чуть раньше картинки, задержка в 10 мс ставит
его вровень: по замерам расхождение от −8 до +10 мс.

## Совместный просмотр

Кнопка «Смотреть вместе» — на странице аниме рядом с «Смотреть» / «Продолжить», в плеере и в верхней панели (👥 с числом
участников). Друзья входят по коду `XXXX-XXXX-XXXX` или по ссылке-приглашению `anixdesktop://watch/<код>` —
серия комнаты открывается сама.

- **Синхронно**: пауза, перемотка, следующая/предыдущая серия и скорость — у всех. Смена серии ждёт, пока она
  загрузится у каждого (не дольше 10 с), и запускает всех разом. Рассинхрон до 2,5 с выравнивается плавно
  скоростью (±10 %), больше — перемоткой с упреждением на время догрузки. По замерам — расхождение 0,0–0,2 с.
- **Очередь «Дальше»**: другое аниме не обрывает серию — выбранное встаёт в очередь («Аня предлагает…»), включить
  может любой, кому разрешено управлять; кончились серии — включается первое из очереди. Хост перетаскивает и
  удаляет, своё предложение может убрать автор. На странице аниме в комнате — «Предложить комнате».
- **Хост** может оставить управление только себе. Ушёл — хостом становится самый давний участник.
- **Мини-плеер**: свернуть плеер в угол и выбирать дальше в каталоге, не прерывая просмотра.
- Видео каждый берёт сам, со своими настройками картинки, звука и качества. Встроенный плеер обязателен: веб-плеер
  синхронизировать нельзя.

**Как устроено, без своего сервера.** Команды идут через три публичных MQTT-брокера сразу (HiveMQ,
test.mosquitto.org, EMQX): сообщение уходит во все, повторы отбрасываются, так что сбой одного не мешает. Брокеры
видят только тему-хеш и шифротекст — ключ AES-GCM и тема выводятся из кода комнаты (PBKDF2, 150 тыс. итераций).
Состояние комнаты и присутствие хранятся у брокеров (retain): вошедший сразу получает их; «последняя воля» брокера
сообщает, что участник пропал без выхода. Часы участников сравниваются пингами, как NTP (могут врать хоть на
минуты), опорную точку раз в 5 с переопубликует самый давний участник. Сторож переподключает брокер, от которого
25 с ничего не приходило: так переживаются обрывы и провайдеры, «замораживающие» долгие соединения с зарубежными
хостингами. Из России (узлы check-host в Москве и Петербурге) все три брокера доступны; на домашнем интернете с
ограничениями, по-хорошему, стоит проверить. Схема синхронизации — по Syncplay и Jellyfin SyncPlay.

## AI-помощник

Вкладка **AI** (шестая в меню) — чат с Claude, который видит аккаунт Anixart и помогает выбрать, что посмотреть,
а по просьбе сам меняет закладки, оценки и коллекции.

**Вход.** По порядку: аккаунт Anixart → аккаунт Claude (подписка Pro/Max или Anthropic Console — откроется окно
входа) → чат. Вход в Claude общий с Claude Code (`~/.claude`): если вы уже вошли там, повторять не нужно.
Запросы расходуют лимиты вашей подписки Claude.

**Что умеет** (`public/js/ai-tools.js`):

| Группа | Инструменты |
|---|---|
| Каталог | `search_releases`, `filter_releases` (жанры, год, статус, серии, «исключить мои списки»…), `get_genres`, `get_release`, `get_voiceovers`, `get_trending`, `get_schedule`, `get_recommendations` |
| Аккаунт | `get_my_list` (Смотрю / В планах / Просмотрено / Отложено / Брошено / Избранное), `get_history`, `get_my_profile`, `get_my_votes` |
| Изменения | `set_list_status`, `set_favorite`, `rate_release` |
| Коллекции | `get_my_collections`, `get_collection`, `create_collection`, `edit_collection`, `add_to_collection`, `remove_from_collection`, `delete_collection` |
| Экран | `open_release`, `open_episodes`, `open_collection` |
| Память | `remember`, `update_memory`, `forget` |
| Интернет | `WebSearch`, `WebFetch` (новости, отзывы) |

Изменения помощник делает сразу, когда пользователь просит, без подтверждений; без просьбы ничего не меняет
(так задано в системном промпте). Упомянутые релизы показываются в чате карточками с постерами.

**Память** — `~/.anixart-desktop/ai/memories/<id аккаунта>.md`, обычный Markdown (можно править руками).
Помощник сам записывает устойчивые предпочтения (жанры, формат просмотра, явные «запомни»); в начале каждой
беседы файл целиком попадает в системный промпт. Чтобы память не съедала контекст, она жёстко ограничена:
40 записей по 200 символов, не больше 4000 символов (≈1–1,5 тыс. токенов). При переполнении `remember`
отказывает и просит сначала объединить или удалить записи — память сжимает сам помощник.
Посмотреть, удалить запись или очистить всё — кнопка «Память» в шапке чата.

**История бесед** — кнопка «История»: до 30 бесед на аккаунт, возврат к беседе восстанавливает и контекст
агента (`session/load`). **«+»** — новая беседа, **«Стоп»** — прервать ответ.

**Модель и глубина рассуждений** — «Настройки → AI-помощник»: по умолчанию **Sonnet 5.5** и effort **medium**;
можно выбрать Opus 5.5, Haiku 5.5, Fable 5.1 и effort от low до max. Смена применяется и к текущей беседе.

**Как устроено**:

```
фронтенд ──POST /ai/*, SSE /ai/events──► server/ai.js ──ACP (stdio)──► claude-agent-acp ──► claude.exe
claude.exe ──MCP (HTTP) /mcp/<ключ>──► server/ai.js ──SSE──► фронтенд выполняет инструмент ──POST /ai/tool-result
```

- Агент — [`@agentclientprotocol/claude-agent-acp`](https://github.com/agentclientprotocol/claude-agent-acp)
  (Agent Client Protocol) со встроенным `claude.exe` из `@anthropic-ai/claude-agent-sdk-win32-x64`.
  Запускается через Electron как Node (`ELECTRON_RUN_AS_NODE`), отдельный Node.js не нужен.
- Инструменты Anixart выполняются во фронтенде (там токен, готовые вызовы API, локальная история, навигация);
  сервер только ретранслирует вызовы. Память обрабатывается на сервере (`server/ai-memory.js`).
- Ограничения агента: из встроенных инструментов Claude Code — только поиск в интернете; рабочая папка —
  пустая `~/.anixart-desktop/ai`; ваши настройки, `CLAUDE.md`, хуки и MCP из `~/.claude` не подключаются
  (`settingSources: []`, `strictMcpConfig`); режим разрешений ручной, инструменты приложения разрешены списком.
- Работает в Windows-приложении и при запуске из исходников после `npm install` (в т. ч. в браузере). Без
  установленных зависимостей (архив «Source code» как есть) вкладка сообщит, что помощник недоступен.

## Вход через соцсети

- **Яндекс, ВКонтакте, Telegram** (только Windows-приложение): официальная страница провайдера открывается
  в окне приложения, оно перехватывает `redirect_uri`, и токен отправляется на бекенд Anixart (`auth/<провайдер>`).
- **Google** (Windows-приложение и браузерная версия): во встроенных окнах Google вход запрещает, поэтому
  открывается обычный браузер со страницей `http://localhost:<порт>/google-auth.html`. Она входит через
  Firebase и возвращает токен в приложение.

Нужны ключи `social.*` в конфиге (см. «Ключи сторонних сервисов»). Вход по логину и паролю работает везде.

## Где хранятся данные

- **localStorage окна приложения** (`%APPDATA%\Anix Desktop` — прежнее название приложения, папку держит
  `electron/main.js`, чтобы после переименования в Anix ничего не потерялось): вход в Anixart, настройки, локальные отметки серий
  и позиции, история поиска, беседы AI (`anixart.ai.chats.<id>`); для улучшения картинки — замеры видеокарты
  (`UPSCALE_BENCH`) и оценки «настоящего» разрешения по источникам (`UPSCALE_NATIVE`, последние 300).
- **`%APPDATA%\Anix Desktop\trt-rtx`** и **`trt-cache`**: библиотеки TensorRT (после «Установить») и собранные под
  видеокарту движки моделей — удалить папки, чтобы убрать ускорение NVIDIA.
- **`~/.anixart-desktop/ai/`**: рабочая папка AI-агента и `memories/<id>.md` — память помощника.
- **`~/.claude/`**: вход в Claude (общий с Claude Code) и сессии агента — по ним восстанавливаются беседы.
- **`%LOCALAPPDATA%nix-desktop-updater`**: скачанный установщик обновления (и копия для докачки следующего).

## Проверка

Тесты запускаются в скрытом окне Electron против живого бекенда Anixart (`npx electron test/<файл>.js`).
Экран считается загруженным, когда закончились запросы, скелетоны и проявление картинок (`test/_settle.js`), —
фиксированных пауз почти нет.
Тесты `ai-*` требуют входа в Claude на машине и расходуют немного лимитов; вход в Anixart в них фиктивный,
а изменяющие запросы к бекенду в `ai-actions` подменены — реальный аккаунт не затрагивается.

## Анимации (Lottie)

Анимации интерфейса (сердце «в избранное», колокольчик, звёзды оценки, галочка в тостах, пустые экраны) —
Lottie, в приложении их проигрывает lottie-web (`public/js/lottie.js`). Источник — сцены плеера скилла
[text-to-lottie](https://github.com/diffusionstudio/lottie) в `tools/lottie-studio/public/projects/anix-ui/`:

```
cd tools/lottie-studio && npm install && npm run dev   плеер (Skia Skottie): кадры, слоты цвета
node tools/lottie-studio/sync.mjs                      сцены → public/lottie/*.json для приложения
```

Цвет в приложении задаёт тема (классы слоёв `cl` и CSS), в плеере — слоты. Отрезки для проигрывания — маркеры сцены.

## Сборка и релиз

```
npm run build:win        портативная папка release\win-unpacked
npm run build:installer  установщик в release\
npm run build:release    файлы релиза в release\: установщик, его .blockmap и latest.yml (для автообновления)
```

**Релизы собирает GitHub Actions** по тегу `vX.Y.Z` — шаги в [RELEASE.md](RELEASE.md). Команды выше —
для локальной сборки.

`config.local.json`, если он есть, попадает в сборку; `node build/release.js --no-keys` — собрать без него.
Иконка: `build/icon.svg` → `npx electron build/make-icons.js` (icon.png, icon.ico, public/icon.png).

`node_modules` распаковываются из asar (`asarUnpack`): адаптер и `claude.exe` запускаются отдельным процессом
и не могут работать из архива.

**Ускорение NVIDIA** (`trt/bin/anix-trt.exe`, кладётся в ресурсы сборки) собирается отдельно, один раз:
`node trt/build.js`. Нужны Visual Studio Build Tools (C++) и CUDA Toolkit 13.x; SDK TensorRT for RTX (заголовки
и import-библиотеки) скрипт скачает в `trt/sdk` сам. Exe не зависит от DLL CUDA и рантайма MSVC; библиотеки
TensorRT подгружает из папки, которую ему передаёт приложение (`%APPDATA%\Anix Desktop\trt-rtx`).
Для тестов без установки библиотек в профиль: `ANIX_TRT_DLLS=trt/sdk/TensorRT-RTX-1.7.1.116/bin`.

## Android

`android/` — то же приложение для телефона (Android 11+): WebView с фронтендом из `public/`. Нашего сервера и
хостинга нет — как и на ПК, «сервер» работает внутри приложения на `127.0.0.1:38371` (порт постоянный: localStorage —
настройки, история, вход — привязан к адресу страницы вместе с портом).

- `LocalServer.kt` — только то, чего не умеет WebView: `/__relay` (запрос наружу с любыми заголовками — User-Agent,
  Sign, Referer, Cookie — и без CORS; только с ключом страницы `relayKey`: сервер виден всем приложениям телефона),
  `/stream` (медиа-прокси, как `handleStream`), вход через Google в системном браузере (`/social/google/*`), фронтенд
  из assets.
- `android/web/shim.js` — `/api/*`, `/parse`, `/probe`, `/social/request|exchange`, `/__info`, `/__features` прямо в
  WebView: подменяет `window.fetch` и выполняет **те же** `server/sign.js`, `server/parsers/*`, `server/social.js`,
  `server/config.js` (в обёртке CommonJS с заменами `crypto`/`Buffer`/`fs`). Подпись, парсеры и вход правятся в одном
  месте — для ПК и телефона. Без сети (`navigator.onLine`) запросы сразу отвечают ошибкой, а не ждут таймаутов.
- `window.anixartNative` на Android (shim.js → мост `anixAndroid`, `MainActivity.Bridge`): ссылки наружу, «Поделиться»
  (системное меню), очистка кэша, вход через Telegram, ВКонтакте и Яндекс в окне приложения (`SocialAuth.kt`,
  перехват редиректа как в Electron), приглашения `anixdesktop://watch/<код>`, обновление (`Updater.kt`).
- Плеер: открыт — горизонталь без системных полос, экран не гаснет, пока идёт серия; свернули приложение во время
  серии — «картинка в картинке» (в окне только видео); погас экран или закрыли PiP — пауза. Тап по видео показывает и
  прячет кнопки (пауза — кнопкой, как в мобильных плеерах; на ПК клик — пауза). Мини-плеер — над нижним меню, с
  кнопками.
- «Назад» — `__anixBack` в shim.js: полный экран → окно, меню, плеер (как Esc) → экран назад → на корне вкладки —
  прошлая открытая вкладка (`backTab` в router.js, каждая вкладка в истории один раз, как в приложении Anixart) →
  вкладок позади нет — свернуть.
- `android/tools/sync-web.mjs` (задача Gradle `syncWeb`) собирает это в `app/build/generated/assets`: без моделей
  апскейла, `android.css` поверх `app.css` (поля нажатия, мини-плеер, PiP, без синей подсветки нажатия WebView),
  правила `:hover` в копии `app.css` — только при наведении мышью (на телефоне `:hover` залипает после тапа), без
  полосы прокрутки ПК (`::-webkit-scrollbar` держит колонку справа — отступ справа шире левого; без неё — системная
  полоса поверх содержимого); `config.local.json` кладётся в сборку, как на ПК.
- Палец (`touch` в platform.js): свайп влево-вправо по содержимому вкладок (`tabs()`) и разделов настроек —
  соседняя вкладка (`swipePages` в ui.js): содержимое, соседняя вкладка и полоска под вкладкой идут за пальцем.
  Свайп вниз у верха экрана — обновить (`pull.js` → `refreshCurrent` в router.js): видимые списки обновляются на
  месте, остальные экраны строятся заново из свежих данных (память недавних экранов сброшена — `forgetRecent` в
  api.js), прежний виден, пока новый не готов. Тост — над нижним меню (`--bottomnav-h`, app.js).
- Плеер пальцем (player.js): свайп по горизонтали — перемотка (на всю ширину — до 3 мин, плашка `.p-hint`), щипок и
  кнопка «Кадр» — вписать, заполнить, растянуть (`object-fit`, настройка `PLAYER_FIT`). Видео — до края экрана и под
  вырезом камеры (`SHORT_EDGES`, у окна плеера нет отступов), кнопки отодвинуты от выреза (`--cut-*`, `__anixInsets`).
- Шапка прячется при прокрутке вниз и возвращается при прокрутке вверх (`hidebar.js`): уезжает `.appbar`, прилипшее
  под ней (`top: var(--stick-top, var(--appbar-h))` — вкладки, чипы серий, поле комментария) поднимается к верху.
  Движение — одно на всех, только `transform` (FLIP, Web Animations): переход `top` отставал от шапки, мелькала щель.
  Программные прыжки прокрутки помечаются `viewport.__jump` — шапку не трогают.
- Вкладки (`tabs()` в ui.js): выбранная — по центру полосы (`centerTab`, не `scrollIntoView` — тот прокручивал и
  экран); у каждой вкладки своя прокрутка экрана (`savedY`; новая — с начала списка под полосой), возврат — прыжком;
  соседние вкладки строятся заранее в простое (как ViewPager), строки списка, пришедшие вне экрана, — без проявления.
- Клавиатура (MainActivity → `__anixIme` → `.kb-open`): нижнее меню и мини-плеер скрыты.
- Страница аниме на телефоне — порядок блоков как в Anixart: описание, «В списках у людей», рейтинг, коллекции, видео,
  кадры, связанные, рекомендуемые, комментарии (классы `rb-*` в release.js, `order` в android.css; колонки — `display:
  contents`). Обновление свайпом, пересобирающее экран, сохраняет выбранные вкладки (router.js `refreshCurrent`).
- Плеер: видео — `position: absolute; inset: 0` во всю область (раньше рамка бралась по пропорциям ролика, и режим
  кадра не менялся); заглушка WebView без кадра — прозрачная (`getDefaultVideoPoster`); перемотка свайпом — как в
  Anixart, p²/25 с (p — % ширины), видео на паузе, пока ведёшь; «Перемотать опенинг» — «+85 с» на кнопке и только без
  метки опенинга (`[hidden]` теперь скрывает всегда — `.icon-btn` перебивал его); «Смотреть вместе» боком — шторка
  во всю высоту справа.
- Нейросеть на телефоне — Anime4K (bloc97, MIT) фрагментными шейдерами WebGL2 (`anime4k-gl.js`, исполнитель
  mpv-хуков; шейдеры — public/models/upscale, в APK — sync-web.mjs). Цепочки `CHAINS`: rm (Restore M + Upscale M), rs
  (Restore S + M), m (M), на 1080p — r (Restore S без увеличения); первым — дебандинг (`Anix_Deband.glsl`, свой
  f3kdb: «квадратики» сжатия на ровных и тёмных участках сглаживаются, линии контрастнее порога не трогаются); поверх —
  RCAS 0.5. Свёртки — в fp16 (`mediump`,
  Adreno вдвое быстрее), координаты — highp, соседи свёрток — `texelFetch`. Замер (`bench`) — пачка кадров подряд, как
  при просмотре (с паузами между кадрами видеокарта сбрасывает частоту, и замер скакал вдвое): Snapdragon 8+ Gen 1,
  720p rm — 11–14 мс, с дебандингом 18–19 мс; 480p — 10 мс. Фоновая проверка (`upscale/phone-check.js`, в простое через 40 с после запуска, без
  открытого плеера; версия `CHECK`): время цепочек на 480/720/1080p и проверка картинки — тестовый кадр через rm в fp16
  и в полной точности, разница с простым растяжением и между собой (журнал `AnixWeb`: «anime4k: картинка …»; на
  телефоне fp16 от полной — 0.14 из 255) и цена дебандинга (rm 720p с ним и без, по очереди). Пункт «Нейросеть» (меню плеера и настройки) виден всегда, выбрать — если хоть одна цепочка успевает (≤ 37.5 мс); до
  ответа — приглушён с подписью (`neuralState`, `NEURAL_HINT`): в настройках проверка начинается сразу (`runCheck` — одна на
  приложение с фоновой), в плеере ждёт его закрытия; конец проверки — событие `a4k-checked`, открытое меню обновляется само; на серии —
  лучшая успевающая, во время просмотра — легче, если кадры идут мимо (player.js, запоминается в `anix.a4k.cap`).
  Проверено и не взято (22.10.2026): свои сети формата Anime4K, дистиллированные из Real-ESRGAN AnimeVideo-v3, и
  ACNet F8B8 — на экране телефона не лучше Anime4K. Отложено: нейросеть на NPU Snapdragon (ONNX Runtime + QNN, ученики AnimeVideo-v3 32x12,
  куски 656x376, 16-битные активации) с нативным плеером ExoPlayer — ближе к учителю, но на экране телефона разница
  невелика, а APK +7 МБ, модуль 15 МБ под каждый чип и лицензия Qualcomm не даёт раздавать его отдельно от приложения.
- Улучшение картинки на телефоне (`sharpen.js`, `has.sharpen`, настройка `PLAYER_SHARPEN`): AMD CAS одним проходом
  WebGL2 по кадру источника (до 1280×960), холст над видео с тем же `object-fit`, кадры — `requestVideoFrameCallback`;
  нет WebGL2 / кадр не прочитать — выключается. Kodik: пункт качества, под которым лежит файл ниже (Kodik дописывает
  «720» файлом 480.mp4), пропускается (`fakeQuality` в server/parsers/index.js).

  и сети — в logcat: `adb logcat -s AnixServer` (адрес, код, начало ответа; без запросов и токенов).
- Полоса перемотки: пока тянут — точка, время и подсказка за пальцем/мышью, видео перематывается, когда отпустили;
  интерфейс не прячется, «Пропустить» посреди жеста не всплывает. У «Смотреть …» — без заливки-отсчёта.
- Обновления по платформам: строка «Платформы: …» в теге — релиз только для неё (release.yml `plan`); приложения ищут
  последний релиз со своим файлом; «Что нового» — общий список и раздел своей платформы (docs/RELEASE.md).
- Фильтр (filter.js): несколько вариантов (жанры с режимом, закладки, озвучки с поиском, возраст) — поле с итогом и
  окно с галочками (`chooseMany`), как в Anixart.
  Комментарии, ответы, «Смотрят», рекомендации, редактор коллекции — без нижнего меню (`body[data-screen]`, router.js).
  Отклик вибрацией (`haptic` в platform.js → `performHapticFeedback`): меню по долгому нажатию, голоса, оценка.
  Разовые подсказки (`hintOnce` в ui.js, `anix.hint.*`). Поле комментария на телефоне — внизу экрана.
- Плеер: блокировка (замок — касания не действуют, ориентация зафиксирована, «Назад» снимает), «Перемотать опенинг
  +1:25» у серий без меток (`PLAYER_REWIND_TIME`), «Только горизонтально» (`PLAYER_LANDSCAPE_ONLY`; выкл — за датчиком).
- Значок приложения на выбор (`activity-alias` `.IconDefault/.IconLight/.IconCarmine`, MainActivity `setIcon`), светлая
  заставка при светлой теме (тема с прошлого запуска — SharedPreferences, `AppTheme.Light`, `setSplashScreenTheme`),
  компактное нижнее меню, формат времени просмотра, «Правила сообщества», голосовой поиск (`RecognizerIntent`), ярлык
  аниме или коллекции на рабочий стол (`ShortcutManager.requestPinShortcut`, значок — постер), «Динамика просмотра»
  в профиле, колонка по центру шире 900 px. `<input type="file">` — системный выбор файла (`onShowFileChooser`),
  сохранение файла (экспорт закладок) — системный «Сохранить как» (`saveFile`, `ACTION_CREATE_DOCUMENT`).
- Экраны, перенятые у Anixart: «Настройки профиля» (`profile-settings.js`: фото с кадрированием, обложка блога, статус,
  никнейм, значок, соцсети, приватность, инкогнито, блоклист, Email, привязка входа, удаление аккаунта), редактор
  коллекции (`collection-editor.js`), подробные настройки уведомлений (из списков, от озвучек, по релизам —
  `notification-releases`), экспорт и импорт закладок (`bookmarks-data.js`, настройки → Дополнительно).
- Ссылки на Anixart (`links.js`): `https://anixart.tv/release/<id>` (и `collection`, `profile`, `channel`, `article`, домены
  и зеркала Anixart), `anixart://release?id=<id>` — экран в приложении: снаружи (intent-filter MainActivity, без
  autoVerify — домены не наши, на Android 12+ их разрешают в «Открывать по умолчанию»: пункт «Открывать ссылки Anixart
  здесь» в «Дополнительно»), изнутри — `<a>` и `window.open`. Ссылку запуска мост отдаёт один раз — `launchLink()`
  в platform.js читает её на всех (приглашения в комнату и links.js).
- Уведомления на телефоне (`push.js`, `NotifyJob.kt`): раз в ~30 мин (есть сеть) JobScheduler запускает скрытый WebView
  со страницей `android/web/background.html` — тот же код запросов (shim.js, api.js, токен в localStorage), —
  `notification/all/0`, новое после прошлой проверки (`anix.notify.last`) — системными уведомлениями (канал
  «Уведомления Anixart», постер, нажатие — `anixart://…`). Разрешение — при первом открытии «Уведомлений» и после
  входа, не при запуске; выключены — плашка на экране уведомлений; переключатель «Уведомления на телефоне» в настройках
  уведомлений (`PHONE_NOTIFY`).
- «Картинка в картинке»: кнопка в плеере (`enterPip`) и сама при сворачивании; в окне — −10 с, пауза, +10 с
  (`RemoteAction` → `__anixMedia`). Медиасессия Android, пока открыт плеер, — кнопки гарнитуры и Bluetooth. В WebView
  нет Media Session API — shim.js подменяет `navigator.mediaSession` и запоминает обработчики плеера.
- На Android нет (`public/js/platform.js`, `has.*`): улучшения картинки, AI-помощника, статуса в Discord, стороннего
  плеера, громкости и «во весь экран» в плеере, своей шапки окна.

```
cd android
./gradlew assembleDebug        app/build/outputs/apk/debug/app-debug.apk (отладка страницы — chrome://inspect)
./gradlew assembleRelease      app/build/outputs/apk/release/app-release.apk (npm run build:android)
```

Нужны JDK 21+ в `JAVA_HOME` (подходит и JDK 25 из Android Studio), Android SDK и Node.js. Версии
(AGP 9.4, Kotlin 2.4 — встроен в AGP, OkHttp 5.5, compileSdk/targetSdk 37) — последние стабильные на 21.10.2026.
`versionCode` — из версии в `package.json` (1.6.0 → 10600).

**Подпись.** Релиз подписывается ключом из `android/keystore.properties` (`storeFile`, `storePassword`, `keyAlias`,
`keyPassword`) или переменных `ANIX_KEYSTORE*` (CI, секреты `ANDROID_KEYSTORE_BASE64` и др. — [RELEASE.md](RELEASE.md));
без ключа — отладочным. Обновление ставится поверх только с тем же ключом — `android/release.keystore` не терять.

**Обновление.** При запуске — последний релиз GitHub с `Anix-<версия>.apk` (CI кладёт его рядом с установщиком
для Windows): то же окно «Вышла новая версия», скачивание с прогрессом, установка — системное окно Android
(«Разрешить установку из этого источника» — один раз).

### Тесты Android

На эмуляторах (по умолчанию AVD `Anix_Test`, свой — `ANIX_AVD`; без PIN-кода) или подключённом телефоне, против живого
бекенда: adb (нажатия пальцем по координатам элементов, системные кнопки) и DevTools страницы в WebView. Бекенд Anixart
недоступен — `SKIP` с причиной. `run-all` гоняет тесты параллельно на эмуляторах `Anix_Test`, `Anix_Test_2`, … (свой
AVD у каждого — копию создаёт сам; несколько экземпляров одного AVD с `-read-only` стартуют, но adb shell у них
зависает), недостающие запускает, пока собирается APK (с нуля, без снимков: ~25–50 с), самые долгие тесты — первыми
(время прошлого прогона — `android/test/shots/.timings.json`). Все вызовы adb — с ограничением времени (2 мин).

```
npm run test:android                    сборка APK и все тесты на 4 эмуляторах; часть: node android/test/run-all.mjs watch pip
  --devices N  --keep  --no-build       сколько эмуляторов; не гасить их в конце (следующий прогон быстрее); без сборки
ANDROID_SERIAL=<устройство> …           всё по очереди на одном устройстве (телефон: adb devices)
node android/test/<тест>.mjs            один тест (первый эмулятор); снимки экранов — android/test/shots
```

| Файл | Что проверяет |
|---|---|
| `bundle.mjs` | сборка для Android без устройства: модули `server/` в WebView как в Node (SHA-256, Buffer, Sign, PKCE, ключи), `:hover` в `app.css` — только при наведении мышью |
| `server.mjs` | `LocalServer.kt` против тестового сервера: relay (заголовки, редиректы, несколько Set-Cookie, тело POST, сетевые ошибки как у fetch), `/stream` (перезапись m3u8, Kodik, Range), статика, вход через Google |
| `launch.mjs` | чистый запуск: каталог и постеры, нижнее меню без AI, тёмные полосы, данные переживают перезапуск |
| `features.mjs` | нет апскейла, AI, Discord, стороннего плеера — ни в настройках, ни в чипе и меню плеера, ни из старых настроек |
| `navigation.mjs` | вкладки пальцем, «Назад»: лист, меню, поиск с клавиатурой, веб-плеер, экраны, на корне — прошлые вкладки, потом свернуть; меню озвучек не открывает клавиатуру |
| `nav.mjs` | «Назад» по прошлым вкладкам (каждая один раз), тост над нижним меню, обновление свайпом вниз: короткое — нет, список — на месте, страница аниме — заново, прокрученный экран и свайп вбок — не обновляют |
| `push.mjs` | уведомления на телефоне: при запуске не спрашивают, первое открытие «Уведомлений» — запрос, «Разрешить» — проверка включена; фоновая проверка присылает новое (серия с озвучкой, друзья), старое и повторы — нет; выключили — плашка «Включить»; выход — проверка выключена |
| `extras.mjs` | разовая подсказка, компактное меню, значок приложения (ярлык запуска сменился), светлая заставка, «Правила сообщества», голосовой поиск, ярлык на рабочий стол, поле комментария внизу, «Поделиться» и «Динамика просмотра» в профиле |
| `editors.mjs` | редактор коллекции (проверки, поиск релизов, тело `collectionMy/create`, выбор обложки), настройки профиля (выбор фото, блоклист), настройки уведомлений, экспорт закладок — «Сохранить как»; ответы сервера подменены |
| `home-ux.mjs` | Главная пальцем: шапка прячется без щели под ней, выбранная вкладка — по центру полосы, своя прокрутка у вкладок (возврат свайпом — сразу, без анимации и без шапки), соседняя вкладка без проявления строк разом; поиск — строка не шире экрана, без нижнего меню над клавиатурой; фильтр — поля с окном галочек; быстрые нажатия по переключателям; «Обзор» без соцсетей Anixart; комментарии аниме — внизу |
| `player-touch.mjs` | плеер пальцем: режим кадра кнопкой и щипком, перемотка свайпом с плашкой (вертикальный — нет), видео под вырезом камеры, кнопки окна PiP и медиасессия по паузе, команды −10 с, пауза, следующая серия, кнопка «Картинка в картинке» |
| `watch.mjs` | каталог → аниме → озвучка → серия играет: горизонталь, полосы, экран не гаснет, тап — кнопки, пауза кнопкой, мини-плеер, «Назад», «Продолжить» после перезапуска |
| `pip.mjs` | «картинка в картинке»: только видео, идёт; вернулись — на весь экран; на паузе — без PiP; погас экран — пауза |
| `links.mjs` | приглашение `anixdesktop://` (запуск и в открытое приложение), ссылки наружу — в браузере, «Поделиться» — меню Android, «Скопировать»; ссылки на Anixart — экран в приложении (запуск по ссылке, в открытое, ссылка в тексте), «Открывать ссылки Anixart здесь» |
| `auth.mjs` | вход: ошибки, клавиатура, кнопки соцсетей, окна Telegram, ВКонтакте, Яндекса (отмена «Назад», перехват редиректа и обмен кода), Google в браузере; с `ANIX_TEST_LOGIN`/`ANIX_TEST_PASSWORD` — настоящий вход |
| `offline.mjs` | без сети — ошибка с «Повторить» за секунды, сеть вернулась — загрузка; сеть пропала по ходу |
| `party.mjs` | совместный просмотр телефон ↔ ПК (`_party-peer.cjs`, настоящие брокеры): участники, чат в обе стороны, «Пригласить», выход |
| `update.mjs` | обновление (поддельный GitHub): окно с «Что нового», скачивание с прогрессом, системная установка — отказ и согласие, данные на месте, «Пропустить эту версию» |
| `touch.mjs` | палец: нажатие без синей подсветки, отступы слева и справа равны (полоса прокрутки не занимает место), свайп по вкладкам главной, «Популярного» и разделам настроек — длинный, быстрый короткий, короткий медленный, у крайней вкладки, вертикальный — прокрутка, карусель внутри вкладки |
| `layout.mjs` | все экраны в обеих темах: ничего не вылезает, кнопки ≥ 32 px, текст ≥ 11 px, подписи в одну строку, нижнее меню не закрывает конец, все вкладки меню на экране; `ANIX_FONT_SCALE=1.3` — крупный шрифт Android, `ANIX_LANDSCAPE=1` — телефон боком (боковое меню) |
